Política de Privacidade

Última atualização: 3 de outubro de 2026

O Audote com Amor é um projeto de estudo criado para aproximar pessoas interessadas em adoção de animais que precisam de um lar.

Esta Política de Privacidade explica quais dados pessoais podem ser coletados pelo site, por que eles são utilizados, como são armazenados e quais são os direitos dos usuários.

Quais dados coletamos

O site pode coletar dados pessoais necessários para o funcionamento da conta e para o processo de contato relacionado à adoção.

  • Dados da conta: nome e e-mail utilizados para criar e identificar a conta.
  • Login com Google: nome, e-mail e foto de perfil disponibilizados pela conta Google. O Audote com Amor não possui acesso à senha da conta Google.
  • Dados do formulário de adoção: nome, CPF, RG, profissão, e-mail e número de WhatsApp.
  • Dados de sessão: informações necessárias para manter o usuário conectado durante a utilização do site.

CPF, RG, e-mail, telefone, nome e profissão são dados pessoais e devem ser tratados de acordo com as finalidades informadas nesta política.

Para que usamos esses dados

Os dados coletados são utilizados para as seguintes finalidades:

  • Criar e identificar a conta do usuário.
  • Permitir o login e o gerenciamento da sessão.
  • Mostrar o nome e a foto do usuário quando necessário dentro do site.
  • Receber informações de pessoas interessadas em realizar uma adoção.
  • Permitir o contato relacionado ao processo de adoção.

Os dados não são vendidos e não são utilizados para publicidade direcionada pelo projeto.

Dados enviados pelo formulário

O formulário de contato e adoção pode solicitar informações como CPF, RG, profissão, e-mail e WhatsApp.

Essas informações são utilizadas para identificar a pessoa interessada e possibilitar o contato relacionado à adoção.

Quando o formulário é enviado por uma pessoa que está logada, o registro pode ser associado ao identificador da sua conta. Quando enviado sem login, o formulário pode ser registrado sem essa associação.

Serviços de terceiros

O site utiliza serviços externos necessários para seu funcionamento:

  • Supabase: utilizado para autenticação, armazenamento e gerenciamento dos dados do sistema.
  • Google: utilizado para autenticação de usuários que escolhem entrar com uma conta Google.
  • Vercel: utilizada para hospedar e disponibilizar o site.

Esses serviços possuem suas próprias políticas de privacidade e termos de uso.

Segurança dos dados

O projeto utiliza mecanismos de autenticação e controle de acesso para ajudar a proteger as informações armazenadas.

O acesso aos dados deve ser limitado às finalidades necessárias para o funcionamento do sistema e do processo de adoção.

🔐 Proteção dos dados

Informações pessoais como CPF, RG, e-mail e WhatsApp devem ser tratadas com cuidado e não devem ser utilizadas para finalidades diferentes das apresentadas nesta política.

Por quanto tempo guardamos

Os dados relacionados à conta são mantidos enquanto a conta do usuário existir, observadas as necessidades do funcionamento do sistema e as obrigações aplicáveis.

Os dados enviados por formulários podem ser mantidos pelo período necessário para atender à finalidade para a qual foram coletados.

Seus direitos

De acordo com a Lei Geral de Proteção de Dados (LGPD), o usuário pode solicitar informações sobre o tratamento de seus dados e, quando aplicável, pedir:

  • acesso aos seus dados pessoais;
  • correção de dados incorretos ou incompletos;
  • atualização de informações;
  • exclusão de dados, quando aplicável;
  • informações sobre o uso de seus dados.
🔒 Privacidade: O Audote com Amor busca utilizar os dados pessoais somente para as finalidades apresentadas nesta Política de Privacidade.

Mudanças nesta política
